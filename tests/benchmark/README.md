# place_id matching benchmark

A small, frozen benchmark for proving place_id matching changes are *real fixes*, not fitted
ones. Built per the Implement+Prove protocol. **Status: scaffold built; not yet proven —
labels are `PENDING_FIXTURE` and fixtures are not captured.**

## Files

| File | Role |
|---|---|
| `place_id_benchmark.csv` | 20-row manifest (identity + source evidence). No labels here. |
| `labels.tune.csv` | Expected outcomes for the 10 TUNE rows. Fill against fetched payloads. |
| `labels.heldout.csv` | Expected outcomes for the 10 HELD-OUT rows. **Seal:** do not read while tuning. |
| `fixtures/<row_id>.json` | Frozen Google candidate payloads (simple + strict). Created by the fetch. |

Generated by `scripts/build_place_id_benchmark.py`. Evaluated by
`scripts/evaluate_place_id_benchmark.py` (replays fixtures through the deterministic matcher).

## Composition (20 rows, stratified 10 TUNE / 10 HELD-OUT)

- 12 base-unresolved (recall stress: venue-hosted, bad-coordinate, generic-name, near-miss)
- 4 resolved-clean (no-regression)
- 2 same-building co-location — must resolve to **distinct** places or defer (collision test)
- 2 short/generic-name (precision)

## Protocol (run in order)

1. **Fetch once (paid, gated):**
   `doppler run -- python3 scripts/capture_benchmark_fixtures.py --confirm-live-api-cost --max-requests 40`
   Writes `fixtures/<row_id>.json` (40 calls = 20 rows × {simple, strict}).
2. **Label against evidence.** For each row set `expected_outcome` ∈ {`place_id`,
   `manual_review`, `no_safe_match`} and `expected_place_id`, justified by the source row +
   the fetched payload. **Freeze labels before touching matching logic.** Do not open
   `labels.heldout.csv` while tuning.
3. **Tune** scoring on the TUNE slice only.
4. **Prove:** `python3 scripts/evaluate_place_id_benchmark.py` — reports TUNE vs HELD-OUT
   gate + precision/recall side by side. A tune/held-out gap = overfitting; report it.

## Integrity rules (enforced by structure, not honour alone)

- Labels are recorded **before** logic and never edited to fit an implementation.
- Held-out labels live in a separate file and are read only by the evaluator, after tuning.
- **No special-casing** in matching logic: no hardcoded names, place_ids, or address strings.
- The evaluator **refuses to run** (exit 1, prints `BLOCKED`) while any label is `PENDING`
  or any fixture is missing — it never fabricates a pass.

## Scope

The evaluator proves the **deterministic scoring** layer. The LLM tier is live and
non-deterministic, so a deferred deterministic outcome (`manual_review`) is the correct
result for both `manual_review` and `no_safe_match` labels.
